# Pixel-Game

A PC-first 2D pixel-art drag racing game built with Godot 4.x.

## Overview

Pixel-Game is an original drag racing game inspired by the genre but creating its own unique identity. The game features:

- Side-view drag racing mechanics
- Car garage and customization
- Career progression system
- Performance upgrades and tuning
- Original pixel-art aesthetic

## How to Open in Godot

1. Open the project in Godot Editor
2. Press "Play" to start the game
3. Use keyboard or controller to play

## Project Architecture

The project follows a modular architecture designed for scalability:

```
Pixel-Game/
├── scenes/           # All game scenes
├── scripts/          # Game logic scripts
├── assets/           # Game art and audio
├── data/             # Game data and definitions
└── tests/            # Test implementations
```
